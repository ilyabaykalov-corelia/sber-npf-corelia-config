# Оформление клиента

В `branding.json` задаются название системы (`title`), основной цвет интерфейса
и пути к логотипу и favicon. Незаданные поля берутся из встроенного конфига
`corelia-web`: для названия это `Corelia`.
Для собственных файлов поместите их в `branding/assets/`, укажите в JSON пути
`/branding/<имя файла>` и пересоберите `corelia-web`. Сборка перенесёт файлы
из этой папки в публичные ресурсы клиента.
